Shirley Casino (offline)

How to run on macOS:
1) Unzip this folder.
2) Open shirley-casino/index.html in Chrome (recommended).
   - If you want, you can also run a tiny local server:
     python3 -m http.server 8000
     then open http://localhost:8000/shirley-casino/index.html

Notes:
- All data is stored in your browser LocalStorage on this computer.
- Use Export to download your data as JSON.
